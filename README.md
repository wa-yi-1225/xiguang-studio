# 析光 Xiguang Studio

**让数据，清晰起来。** 由哇一创作的本地数据分析桌面工作台。

Windows 用户下载应用后即可使用，**无需安装 Python、Node.js、Excel 或其他编程环境**。数据处理在本机完成，无分析 API 费用。

## 可以做什么

- 导入 CSV、TSV、分隔文本 TXT、XLSX、XLS、JSON；支持中文 UTF-8 / GB18030、UTF-16、多工作表、分隔符和表头调整、预览与手动类型纠正。
- 检查缺失、重复、类型、前导零编号，保留导入与手动转换记录；可移除完全重复行、恢复导入版本。
- 一键运行适用分析，或选择模块、变量与描述指标，仅求均值、仅生成图表也可以。
- 描述统计、直方图与频数图、Pearson / Spearman 相关、多元 OLS 线性回归、标准化 PCA、K-means、Welch t / Welch ANOVA、日期趋势。
- 导出可打印 PDF、离线 HTML、CSV 统计表 / 数据、JSON 完整结果、SVG 分布图。
- 本地账户、访客空间、项目保存与恢复。账户密码使用加盐 scrypt；不同账户项目分开保存。

## 使用流程

1. 导入文件或打开 96 条合成数据的内置示例。
2. 在「数据管理」检查工作表、编码、表头和列类型；纠正后点「重新识别」。手动转换失败的值会设为缺失并记录，不会静默改写原始文件。
3. 点「一键分析」，或在「描述统计 / 探索建模」勾选模块与变量后运行。只想求均值时，仅选描述统计和均值指标即可。
4. 在「图表工坊」查看分布、关系、相关与日期趋势；在「报告导出」选择报告章节。
5. 到「本地项目」命名并保存，之后可恢复数据和分析结果。

## 方法与边界

这是一套可运行的探索分析工具，不是“任何数据都能正确建模”的承诺。分析方法随数据类型、样本量与条件自动选择；不适合的模块会记录跳过原因。

- 最大源文件 20 MiB、100,000 行、200 列；本地项目与导出文件各 64 MiB。复杂或压缩展开过大的工作簿会拒绝。CSV 解析在 Worker 中进行，可取消，不锁住主界面。
- 不支持密码保护 / 加密 Excel、ZIP64 Excel、嵌套 JSON 的自动展平。Excel 公式读取文件保存的缓存值，不会执行宏、重新计算公式或联网。
- 表头、日期、类型识别属于启发式判断，可手动调整。缺失不会自动填补；不会自行删除异常值。保留长数字与前导零标识，严格转换失败会明确记录。
- 标准差采用样本公式，四分位数线性插值，异常值使用 1.5×IQR 提示。
- 相关按成对有效样本；回归/PCA/聚类使用所需变量的完整样本。回归默认最后数值变量为目标，可在界面修改；报告标注样本内拟合，未自动交叉验证。相关不代表因果。
- PCA/聚类标准化；PCA图形得分最多 2,000 行。大数据 K-means 最多用 5,000 个等距样本拟合，然后分配所有完整样本，并记录抽样说明。相关最多24、PCA/聚类最多20、回归最多12个数值变量；超过时需缩小选择。大数据 Spearman 会明确跳过以限制资源。
- 组间检验自动取适用的分类变量与目标变量，仅探索，不作多重检验校正；独立性、分布和研究设计需要人判断。
- 本地账户用于分隔工作空间，**没有云同步，不是磁盘加密**，忘记密码不能恢复。数据默认保存在 Windows 当前用户的 `%APPDATA%/析光` 下，卸载默认保留数据。
- 本版本未包含时间序列预测、优化求解、专业领域模型或自动论文写作；不声称覆盖所有数学建模任务。
- 已进行当前 Windows 机器上的技术检查；未声称在所有电脑、全新虚拟机或所有真实数据上验证。

## 开发与复现

普通用户不需要这些步骤。开发者使用 Node.js 24、npm：

```powershell
npm ci
npm test
npm run build
npm run desktop
npm run package
npm run smoke
```

`release/` 包含安装包、便携版和独立运行目录；`qa/` 保存本地自检与截图（不提交个人路径和临时数据）。`scripts/smoke.mjs` 会移除 Node/Python 所在 PATH，以打包后的程序执行真实 Worker 分析、账户隔离、项目读写和 PDF 导出；这与干净系统验证仍有区别。

开发服务器用 `npm run dev`，另一个终端设置 `XIGUANG_DEV_URL=http://127.0.0.1:5178` 再运行桌面程序。正式版仅加载本地打包页面，不连接 CDN。
